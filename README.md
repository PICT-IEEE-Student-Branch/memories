## Adding a gallery

1. Put the photos in a **Google Drive folder** and set its sharing to **"Anyone with the link → Viewer"**. Never use *Editor*: anyone who finds the link could delete or replace the photos.
2. Add a row to the table above: event, month and year, and the link.
3. Keep the photos themselves on Drive, not in this repo. That keeps the repo light and lets the folder owner take a photo down if someone asks.
4. Respect people's wishes: if someone asks not to be in a public gallery, remove those photos.
